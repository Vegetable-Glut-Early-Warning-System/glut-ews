# v0 outputs report

The `outputs` tables hold **v0** outputs generated by `scripts/build_db.py` (seed 20261018) so that all four modules can work in parallel. Each module replaces its own table with a v1 result through `publish_output` and `scripts/rebuild_db.py`; downstream modules then re-run.

## C1 — `outputs.c1_glut_season` (756 rows: season × centre × crop, traded combinations only)

Rule: real price (÷ CCPI) relative to its 53-week rolling median, divided by the median ratio for the same calendar week (removes trend and the normal seasonal dip); glut week if below 0.70; season = Glut if at least 4 glut weeks in the harvest window.

- Glut rate: **33.5%**

## C2 — `outputs.c2_pressure_score` (402 rows: footprint pairs only)

Entropy weights: price incentive 0.095, planting target 0.196, area momentum 0.108, past profitability 0.151, recent arrivals 0.088, pre-season rainfall 0.171, glut-prone season 0.192. `top_drivers` lists the three largest contributions per row.

## C3 — `outputs.c3_training_label` and `outputs.c3_risk_prediction` (402 rows each)

Realised label = 0.55·z(centre glut share in harvest window) + 0.45·z(district production ÷ prior 3-season same-type mean); High ≥ 85th percentile, Medium ≥ 55th.

Learnability check (gradient boosting on pre-season features; test = 2024/25 Maha – 2025 Yala):

| Added label noise (relative SD) | Macro-F1 on test |
|---|---|
| 0.0 | 0.427 |
| 0.4 | 0.423 |
| 0.7 | 0.456 |
| 1.0 | 0.405 |

Chosen: noise 0.7 → macro-F1 **0.456**: learnable but not trivially predictable. Label shares: Low 55%, Medium 30%, High 15%.

`c3_risk_prediction` simulates a classifier (about 60–65% agreement with the label) with calibrated-looking probabilities and reasons. C4 must consume predictions, never the realised label.
